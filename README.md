# PHP BioLinks

Projeto desenvolvido durante a **Formação PHP** da [Rocketseat](https://rocketseat.com.br), como parte prática do curso.

Uma aplicação de bio links (estilo Linktree) onde cada usuário tem uma página pública com seus links, foto e descrição — acessível via `/{handler}`.

---

## Tecnologias

- **PHP 8.2+**
